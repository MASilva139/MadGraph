# Entorno de MadGraph
El presente repositorio presentará las modificaciones realizadas al entorno de MadGraph, empleadas para las prácticas finales y el EPS. Así mismo servirá como una copia de seguridad en caso de que una modificación arruine el simulador.

Para revisar la instalación del entorno conda en donde se ejecuta MadGraph, y la configuración del mismo véase el repositorio [ECFM-PF](https://github.com/MASilva139/ECFM-PF).
